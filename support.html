Happy Markdown 技术支持

本地优先的 Markdown 编辑器。文稿是以 .md 保存的普通文件，放在你选择的文件夹里，断网也能写作与导出。

运行要求

macOS 10.15 或更高版本。App Store 版本在系统沙箱中运行。

常见问题

首次打开时为什么要求选择文件夹

沙箱下的应用只能访问用户通过系统面板授权的目录。首次打开时选择一个工作文件夹即可，应用会用安全作用域书签记住它，下次启动继续可用。需要更换目录时，从侧栏重新选择。

AI 功能提示无法连接

AI 功能需要自备模型。默认连接本机 127.0.0.1:11434 上的 Ollama 服务，也可以在设置里填写自己的 API 地址。没有可用模型时该面板会提示无法连接，编辑、预览、公式、图表、乐谱与导出均不受影响。

文稿保存在哪里

保存在你选择的工作文件夹里，就是普通的 .md 文件。应用不向云端复制，也没有账号与同步，卸载应用不会删除这些文稿。

如何导出

菜单里可以导出 HTML 单文件、PDF、Word 与 PowerPoint。PDF 走系统打印面板；Word 与 PowerPoint 中的公式与图表会渲染成图片嵌入。

版本控制怎么用

对工作区开启版本控制后，应用会随你的操作提交快照。可以查看某个文件的历次版本、与原文件并排比较，也可以在改动不满意时还原到其中一版。

是否需要订阅

不需要。应用为一次性购买，没有订阅，也没有内购项目。

如何申请退款

Support

A local-first Markdown editor. Your documents are ordinary .md files in a folder you choose, and they work without an internet connection.

Requirements

macOS 10.15 or later. The App Store build runs inside the system sandbox.

Why does it ask for a folder the first time

A sandboxed app can only reach a folder that the user grants through the system panel. Choose a working folder once and the app remembers it with a security-scoped bookmark, so it is available on the next launch. Pick another one from the sidebar whenever you need to.

AI assist says it cannot connect

AI assist needs your own model. It connects by default to Ollama on 127.0.0.1:11434, and you can enter your own API endpoint in Settings. Without a model the panel reports that it cannot connect; editing, preview, math, diagrams, music notation and all exports keep working.

Where documents are stored

In the working folder you chose, as ordinary .md files. Nothing is copied to a cloud service, there is no account and no sync, and removing the app does not delete your documents.

Exporting

Export to a single HTML file, PDF, Word and PowerPoint from the menu. PDF goes through the system print panel; math and diagrams are rendered as images inside the Word and PowerPoint output.

Version control

Turn on version control for a workspace and the app commits snapshots as you work. You can browse a file's earlier versions, compare them side by side with the current file, and restore one if you change your mind.

Subscription

Not required. The app is a one-time purchase, with no subscription and no in-app purchases.

Refunds

Purchases and refunds made through the App Store are handled by Apple. Submit a request at reportaproblem.apple.com.
