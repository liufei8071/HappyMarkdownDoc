Happy Markdown 技术支持

本地优先的 Markdown 编辑器。文稿是以 .md 保存的普通文件，放在你选择的文件夹里，断网也能写作与导出。

运行要求

macOS 10.15 或更高版本（App Store 版本在系统沙箱中运行）；Windows 10 版本 2004 （内部版本 19041）或更高，或 Windows 11。

Windows 版使用系统已安装的 Microsoft Edge WebView2 运行时：Windows 11 自带， Windows 10 通常随 Edge 安装。

常见问题

首次打开时为什么要求选择文件夹

沙箱下的应用只能访问用户通过系统面板授权的目录。首次打开时选择一个工作文件夹即可，应用会用安全作用域书签记住它，下次启动继续可用。需要更换目录时，从侧栏重新选择。

Windows 上双击后没有反应

通常是缺少 Microsoft Edge WebView2 运行时。请先确认：设置 → 应用 → 已安装的应用里搜索 WebView2，或查看 C:\Program Files (x86)\Microsoft\EdgeWebView\Application 下是否有版本目录。若没有，请从 微软官方页面 下载与系统一致的 Evergreen Standalone Installer（x64 或 ARM64），安装后重新启动应用。 Windows 11 通常已自带；Windows 10 多数机器随 Edge 安装。

安装后仍无法启动时，请把 Windows 版本与错误信息发到支持邮箱。如果应用能启动但随后 异常退出，日志在 %LOCALAPPDATA%\com.happymarkdown.desktop\logs， 请一并附上。

AI 功能提示无法连接

AI 功能需要自备模型。默认连接本机 127.0.0.1:11434 上的 Ollama 服务，也可以在设置里填写自己的 API 地址。没有可用模型时该面板会提示无法连接，编辑、预览、公式、图表、乐谱与导出均不受影响。

文稿保存在哪里

保存在你选择的工作文件夹里，就是普通的 .md 文件。应用不向云端复制，也没有账号与同步，卸载应用不会删除这些文稿。

如何导出

菜单里可以导出 HTML 单文件、PDF、Word 与 PowerPoint。PDF 走系统打印面板；Word 与 PowerPoint 中的公式与图表会渲染成图片嵌入。

版本控制怎么用

对工作区开启版本控制后，应用会随你的操作提交快照。可以查看某个文件的历次版本、与原文件并排比较，也可以在改动不满意时还原到其中一版。

是否需要订阅

不需要。应用为一次性购买，没有订阅，也没有内购项目。

Support

A local-first Markdown editor. Your documents are ordinary .md files in a folder you choose, and they work without an internet connection.

Requirements

macOS 10.15 or later (the App Store build runs inside the system sandbox); Windows 10 version 2004 (build 19041) or later, or Windows 11.

The Windows build uses the system Microsoft Edge WebView2 Runtime: included in Windows 11 and usually installed with Microsoft Edge on Windows 10.

Why does it ask for a folder the first time

A sandboxed app can only reach a folder that the user grants through the system panel. Choose a working folder once and the app remembers it with a security-scoped bookmark, so it is available on the next launch. Pick another one from the sidebar whenever you need to.

The app does not start on Windows

This usually means the Microsoft Edge WebView2 Runtime is missing. Check Settings → Apps → Installed apps for WebView2, or look for a version folder under C:\Program Files (x86)\Microsoft\EdgeWebView\Application. If it is missing, download the Evergreen Standalone Installer (x64 or ARM64 to match your system) from Microsoft's official page and relaunch the app. Windows 11 usually includes it; most Windows 10 machines have it with Microsoft Edge.

If it still does not start, email us your Windows version and any error message. If the app starts and then exits unexpectedly, attach the logs from %LOCALAPPDATA%\com.happymarkdown.desktop\logs.

AI assist says it cannot connect

AI assist needs your own model. It connects by default to Ollama on 127.0.0.1:11434, and you can enter your own API endpoint in Settings. Without a model the panel reports that it cannot connect; editing, preview, math, diagrams, music notation and all exports keep working.

Where documents are stored

In the working folder you chose, as ordinary .md files. Nothing is copied to a cloud service, there is no account and no sync, and removing the app does not delete your documents.

Exporting

Export to a single HTML file, PDF, Word and PowerPoint from the menu. PDF goes through the system print panel; math and diagrams are rendered as images inside the Word and PowerPoint output.

Version control

Turn on version control for a workspace and the app commits snapshots as you work. You can browse a file's earlier versions, compare them side by side with the current file, and restore one if you change your mind.

Subscription

Not required. The app is a one-time purchase, with no subscription and no in-app purchases.

サポート

ローカル優先の Markdown エディターです。原稿は選んだフォルダーにある普通の .md ファイルで、ネットワークにつながっていなくても執筆と書き出しができます。

動作環境

macOS 10.15 以降（App Store 版はシステムのサンドボックス内で動作します）、または Windows 10 バージョン 2004（ビルド 19041）以降もしくは Windows 11。

Windows 版はシステムにインストール済みの Microsoft Edge WebView2 ランタイムを使用します。 Windows 11 には標準で入っており、Windows 10 では通常 Microsoft Edge と一緒にインストールされます。

初回にフォルダーの選択を求められる理由

サンドボックス内のアプリは、ユーザーがシステムのパネルで許可したフォルダーにしかアクセスできません。初回に作業フォルダーを一度選べば、セキュリティスコープ付きブックマークとして記憶され、次回以降も使えます。別のフォルダーに変えるときはサイドバーから選び直せます。

Windows でダブルクリックしても起動しない

多くの場合 Microsoft Edge WebView2 ランタイムが入っていません。設定 → アプリ → インストールされているアプリで WebView2 を検索するか、C:\Program Files (x86)\Microsoft\EdgeWebView\Application にバージョンのフォルダーがあるか確認してください。無い場合は Microsoft の公式ページ から、システムに合った Evergreen Standalone Installer（x64 または ARM64）をダウンロードしてインストールし、アプリを起動し直してください。Windows 11 には標準で入っており、Windows 10 の多くは Microsoft Edge と一緒に入っています。

それでも起動しない場合は、Windows のバージョンとエラーメッセージをサポート宛にお送りください。起動したあと異常終了する場合は %LOCALAPPDATA%\com.happymarkdown.desktop\logs のログも添えてください。

AI 機能が接続できないと表示される

AI 機能にはご自身のモデルが必要です。既定では本機の 127.0.0.1:11434 で動く Ollama に接続し、設定で独自の API アドレスも指定できます。モデルが無いとそのパネルに接続できない旨が表示されますが、編集、プレビュー、数式、図表、楽譜、書き出しはすべて使えます。

原稿の保存場所

選んだ作業フォルダーに、普通の .md ファイルとして保存されます。クラウドへの複製はなく、アカウントも同期もありません。アプリを削除しても原稿は残ります。

書き出し

メニューから HTML 単一ファイル、PDF、Word、PowerPoint に書き出せます。PDF はシステムの印刷パネルを使います。Word と PowerPoint では数式と図表が画像として埋め込まれます。

バージョン管理

ワークスペースでバージョン管理を有効にすると、作業に合わせてスナップショットが保存されます。ファイルの過去のバージョンを一覧し、現在のファイルと並べて比較し、気が変わったらその一つに戻せます。
